# SASHOC South Boys Regional Fixtures

- `/index.html` is a mobile-friendly single-page app for parents to browse upcoming fixtures and filter them by age group, pool, or team.
- `/participating-teams.csv` contains the team pools parsed from the 2026 draft fixture document.
- `/fixtures.csv` contains the scheduled fixtures, breaks, and prize-giving rows parsed from the same document.
- The U18 teams are marked as `SINGLE POOL` because the source document provides one U18 group instead of Pool A/Pool B splits.
- Team names and empty fixture slots are preserved exactly as they appear in the draft source document.
